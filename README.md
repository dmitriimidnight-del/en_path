# en_path

Карманный тренажёр английского: глаголы, 12 времён и разговорные конструкции. Устанавливается на телефон как приложение и работает без интернета.

**Открыть:** https://dmitriimidnight-del.github.io/en_path/

## Как установить на телефон

- **Android (Chrome, Яндекс Браузер):** открыть ссылку → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».

После первого открытия приложение работает офлайн. Обновления подтягиваются сами при запуске с интернетом.

## Файлы

- `index.html` — всё приложение (данные, логика, стили).
- `manifest.webmanifest`, `icons/` — иконка и название для установки.
- `sw.js` — офлайн-кэш. При изменении иконок или манифеста увеличь `CACHE` в нём.

## Что внутри

**Глаголы**
- 184 неправильных и 413 правильных глаголов с переводом, поиск по-английски и по-русски.
- По нажатию на строку: форма he/she/it, V-ing, как читается окончание -ed, озвучка, переход во «Времена».
- Режим «Учить» размывает V2 и V3, чтобы проверять себя.

**Времена**
- Все 12 времён в утверждении, вопросе и отрицании для любого местоимения.
- Работает с любым глаголом из списка: выбор через поиск или 🎲.
- У каждого времени — маркеры (already, by Friday, at the moment…).
- Нажатие на строку проговаривает фразу.

**Конструкции**
- 22 конструкции: used to, be going to, had better, would rather, I wish, условные предложения и другие.
- У каждой — формула, смысл, подсказка по употреблению и 3 примера с переводом.

**Тренажёр**
- *Формы*: ввод V2 и V3 или карточки с самопроверкой. Наборы: базовые (86), + средние, все.
- *Времена*: «Выбор» (узнать время / выбрать фразу), «Ввод» (написать фразу целиком), «Маркеры» (поставить глагол в предложение по маркеру).
- *Конструкции*: карточки (русская фраза → сказать по-английски) и заполнение пропусков. Можно тренировать одну конструкцию прямо из справочника.
- Интервальные повторения: карточка возвращается через 1, 3, 7, 16, 35, 90 дней; ошибка отправляет её в начало. До 10 новых карточек в день.
- Цель — 20 ответов в день и счётчик серии дней 🔥.
- Ответы проверяются без учёта регистра и сокращений: don't = do not, апостроф можно не ставить.

Прогресс хранится в браузере (localStorage).
