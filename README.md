# en_path

Карманный тренажёр английских глаголов и времён. Устанавливается на телефон как приложение и работает без интернета.

**Открыть:** https://dmitriimidnight-del.github.io/en_path/

## Как установить на телефон

- **Android (Chrome, Яндекс Браузер):** открыть ссылку → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».

После первого открытия приложение работает офлайн. Обновления подтягиваются сами при запуске с интернетом.

## Файлы

- `index.html` — всё приложение (данные, логика, стили).
- `manifest.webmanifest`, `icons/` — иконка и название для установки.
- `sw.js` — офлайн-кэш. При изменении иконок или манифеста увеличь `CACHE` в нём.

## Что внутри

**Глаголы**
- 184 неправильных и 413 правильных глаголов с переводом, поиск по-английски и по-русски.
- По нажатию на строку: форма he/she/it, V-ing, как читается окончание -ed, озвучка, переход во «Времена».
- Режим «Учить» размывает V2 и V3, чтобы проверять себя.

**Времена**
- Все 12 времён в утверждении, вопросе и отрицании для любого местоимения.
- Работает с любым глаголом из списка, а не с фиксированным набором: выбор через поиск или 🎲.
- Нажатие на строку проговаривает фразу.

**Тренажёр**
- *Формы глаголов*: вводишь V2 и V3. Три уровня: базовые (86), средние, все. Глагол считается выученным после 3 верных ответов подряд, ошибки возвращаются чаще.
- *Времена*: узнать время по фразе или собрать фразу по названию времени. Сетка точности по каждому из 12 времён показывает слабые места.

Прогресс хранится в браузере (localStorage).
