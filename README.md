# en_path

Карманный тренажёр английского: глаголы, 12 времён и разговорные конструкции. Устанавливается на телефон как приложение и работает без интернета.

**Открыть:** https://dmitriimidnight-del.github.io/en_path/

## Как установить на телефон

- **Android (Chrome, Яндекс Браузер):** открыть ссылку → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».

После первого открытия приложение работает офлайн. Обновления подтягиваются сами при запуске с интернетом.

## Файлы

- `index.html` — всё приложение (данные, логика, стили).
- `manifest.webmanifest`, `icons/` — иконка и название для установки.
- `sw.js` — офлайн-кэш. При изменении иконок или манифеста увеличь `CACHE` в нём.

## Что внутри

Нижнее меню: **Сегодня · Уроки · Словарь · Справочник · Тренажёр**.

**Сегодня** — главный экран
- Занятие примерно на 10 минут, которое приложение собирает само: повторение по расписанию, новые слова, фраза, глагол или конструкция (сначала знакомство, потом проверка), ошибки из журнала, «Собери фразу», времена, диктант и говорение. Типы заданий чередуются.
- Карточка «Следующий урок», журнал ошибок, уровень A1 / A2 / B1+.
- Настройки: цель на день, сколько новых карточек давать, скорость озвучки.
- Резервная копия: сохранить прогресс в файл и загрузить обратно.

**Уроки «Основы A1»** — 14 тем: to be, артикли, множественное число, местоимения, this/that, have/has, Present Simple, порядок слов, вопросительные слова, предлоги времени и места, some/any/much/many. В каждом уроке короткое объяснение и 7–10 упражнений: вставь слово, выбери, собери фразу, переведи. Упражнения потом возвращаются в занятиях по расписанию.

**Словарь**
- 346 слов в 16 темах (семья, дом, еда, город, транспорт, время, числа, работа, тело, одежда, цвета, погода и другие). Кнопка «знаю» убирает слово из новых; через неделю оно придёт на проверку.
- 81 фраза для 10 ситуаций: знакомство, кафе, магазин, дорога, гостиница, работа, здоровье и другие.

**Справочник** — глаголы (184 неправильных и 413 правильных), 12 времён с маркерами, 27 конструкций.

**Тренажёр** — режимы: Слова (выбор, карточки, ввод), Фразы (карточки, «Скажи»), Собери фразу, Формы глаголов, Времена, Конструкции, Ошибки.

**Как устроено обучение**
- Интервальные повторения: 1, 3, 7, 16, 35, 90 дней; ошибка отправляет карточку в начало.
- Журнал ошибок: задание уходит из журнала после 2 верных ответов подряд.
- Цель на день и счётчик серии дней 🔥.
- Проверка без учёта регистра и сокращений: don't = do not, апостроф можно не ставить.

Распознавание речи работает в Chrome и Яндекс Браузере (нужен интернет и доступ к микрофону); без него — самопроверка вслух. Прогресс хранится в браузере (localStorage) — делай резервную копию.
